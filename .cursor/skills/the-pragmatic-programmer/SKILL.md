# The Pragmatic Programmer Skill

Credit: [ciembor/agent-rules-books](https://github.com/ciembor/agent-rules-books) `the-pragmatic-programmer/` (MIT, Copyright (c) 2026 Maciej Ciemborowicz). Inspired by *The Pragmatic Programmer* by Andrew Hunt and David Thomas. Practical agent instructions, not official book text and not a substitute for the book.

Use this skill when a task needs a general engineering bias: own the outcome, keep one source of truth, keep unrelated concerns independent, and get feedback before calling the work done.

Before making design or code decisions, read and apply [the-pragmatic-programmer.mini.md](the-pragmatic-programmer.mini.md).
